# اقتراح نظام التصميم الموحّد لحكيم

يُبنى على **التوكنز الموجودة فعلًا** (ناضجة) مع سدّ الفجوات المرصودة. الهدف: واجهة عربيّة احترافيّة هادئة موثوقة — لا حكوميّة تقليديّة ولا دردشة عامّة.

## 1) الألوان (من `identity.css` — تُعتمد كما هي)
```
Primary   petrol #0E3435 · petrol-600 #1F4F4C
Accent    copper #C69763 · copper-deep #A9793F · copper-soft #E8D6BC
Ink       #12211F + سلّم شفافيّة 82/70/60/42/20/15/10/5%
Surface   عاجيّ (ivory) — خلفيّة/بطاقات
```
**فجوة تُسدّ:** توثيق صريح لِـ Success/Warning/Error/Info/Focus-ring كتوكنز مسمّاة + **قياس تباين WCAG AA** للنصوص الثانويّة (`--ink-60/40`) على العاجيّ (A11Y-006).

## 2) المسافات (سدّ الفجوة)
```
4 · 8 · 12 · 16 · 20 · 24 · 32 · [40 مضافة] · 48 · [64 مضافة]
```

## 3) الأنصاف والظلال (تُعتمد)
`radius 8/12/16/20/24` · `shadow xs/sm/md/lg` (بترول شفّاف).

## 4) الطباعة (سلّم مقترح فوق الخطوط الحاليّة)
`Display · H1 · H2 · H3 · H4 · Body-L · Body · Body-S · Label · Caption · Legal-Citation (Amiri) · Mono (رقم المادة)`.
خطوط: IBM Plex Sans Arabic (عرض/متن) · Amiri (اقتباس قضائيّ) · IBM Plex Mono (أرقام/مواد/مبالغ).

## 5) الأيقونات
lucide (أساسيّة، 24px إجراءات) + Hakeem/Ja (مجاليّة) — **بدليل استخدام** وسلّم 16/20/24/32.

## 6) المكوّنات المعياريّة المطلوب توثيقها
- **الأزرار:** أساسيّ/ثانويّ/شبح/خطر + حالات Hover/Focus/Pressed/Loading/Disabled.
- **الحقول:** Label دائم + Helper + Error + Success (لا Placeholder-only).
- **البطاقات · الجداول · النوافذ · التنبيهات.**
- **صندوق المحادثة:** المكوّن المحوريّ — مواصفة موحّدة (المُنشئ، الأدوات، الجلسات، الإجابة، المراجع، التكلفة).
- **الاستشهاد القانونيّ / عرض المادّة النظاميّة / عرض الرصيد** — أنماط مخصّصة لحكيم.

## 7) حالات التفاعل الإلزاميّة
Loading (Skeleton) · Empty · Error · Focus-visible · Reduced-motion (موجود) · أهداف لمس ≥44px.

**النتيجة:** لا يحتاج حكيم نظام تصميم جديدًا — بل **توثيق + سدّ فجوات** (المسافات 40/64، حالات الأزرار، Label الحقول، قياس التباين، دليل الأيقونات، توحيد صندوق المحادثة).
