# تدقيق إمكانية الوصول

**المصدر:** فحوص DOM آليّة حقيقيّة (58 صفحة) + تحليل مصدريّ. **قيد:** axe-core لم يُشغَّل (تحتاج حزمة إضافيّة)؛ التباين اللونيّ لم يُقَس آليًّا بعد.

## ما تحقّق (🟢)
- **RTL/lang:** كل صفحة `lang=ar dir=rtl` + `viewport-fit=cover`.
- **الحقول العامّة:** لا حقول بلا Label على الصفحات العامّة، لا صور بلا alt، لا روابط فارغة.
- **صفر أخطاء Console** على معظم الأسطح (عدا أسطح البحث/المحادثة — PERF-001).
- عناصر تحكّم لوحة المفاتيح موجودة في المكوّنات (`SearchAutocomplete`: `role=listbox`, `aria-activedescendant`؛ `CommandPalette`: ArrowUp/Down/Enter/Esc).
- `focus-visible` و`prefers-reduced-motion` معرّفان في `app/identity.css`.

**الحل (A11Y-002):** شعار الغلاف → `<p>`/`aria-label`، `<h1>` واحد لكل صفحة.
**الحل (A11Y-003/005):** `<label>`/`aria-label` لكل حقل وزرّ أيقونيّ.
**معيار القبول:** 0 مخالفات axe-core خطيرة/حرجة على المسارات الأساسيّة؛ h1 واحد/صفحة؛ عبور كامل بلوحة المفاتيح.

**الخطوة المكمّلة:** تشغيل `@axe-core/playwright` + فاحص تباين على المسارات الأساسيّة (جاهز عند توفّر الحزمة/الجلسة).
