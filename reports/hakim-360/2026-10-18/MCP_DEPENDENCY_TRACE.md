# تتبع اعتماد MCP — HKM-031

## `/mcp`

1. `gate` ثم `mcpAccessMode`: مغلق يعيد 503، والمصادقة تفرض الرمز، والفتح مسار بلا رمز.
2. `withMcpAuth` / `verifyMcpRequest`: مفتاح مشترك، أو منحة hk2 إذا فُعّل ربط الحساب، أو مفتاح `hk_live` على `api_keys`. غير ذلك 401 في وضع المصادقة.
3. معالج MCP بلا حالة. أدوات حكيم تمر في `runMcpTool`. أدوات أمان على المسار نفسه لا تمر في هذا المغلف.
4. الأدوات تقرأ عبر Prisma و`hybridSearch` وبحث الأحكام. لا توليد Claude داخل أدوات MCP التي فُحصت. التضمين هو النداء الخارجي المدفوع إن وُجد مفتاح، وهو غائب في هذه الجلسة.

لا تجمع اتصالات خاص بـ MCP في الكود. العميل مفرد بلا `connection_limit` ظاهر.

## `/aman/mcp`

بلا `gate` وبلا `withMcpAuth`. أدوات فرز تصنيفي بلا كتابة قاعدة. ليس مسار مهلة البحث.
