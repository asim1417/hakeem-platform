## 1. التعريف التنفيذي

**حكيم** منصة عمل ومعرفة قانونية سعودية تجمع في تطبيق واحد: السؤال القانوني المؤصّل، إدارة المحادثات والجلسات، النواة القانونية، تحليل القضايا، المعاون القضائي، المحاكاة القضائية التدريبية، معالجة المستندات، إدارة الملفات، التدريب، والتشغيل الإداري والتجاري.

لا يقتصر المنتج على إظهار نصوص الأنظمة؛ بل يحاول نقل المستخدم من **الواقعة أو المستند** إلى **البحث والاستناد والتحليل وخطة العمل أو المسودة** مع إبقاء القرار المهني والبشري للمستخدم.

**[مثبت]** الواجهة الرئيسية بعد الدخول تجعل «اسأل حكيم» نقطة البداية، وتعرض أدوات أعمق: المعاون القضائي، منصة الوثائق، النواة القانونية، ومساحة المستخدم.  
الدليل: `app/dashboard/page.tsx`، `components/dashboard/DashboardWorkbench.tsx`.

## 2. الرؤية والرسالة

### الرؤية
بناء بيئة عمل قانونية سعودية موحدة تساعد الممارس على فهم المسألة، الوصول إلى مصادرها، تنظيم ملفها، واستخراج أعمال قانونية قابلة للمراجعة.

### الرسالة
تقليل تشتت العمل بين محرك البحث، قارئ الوثائق، المحادثة العامة، أدوات الصياغة، وسجل القضية؛ وربطها بنواة قانونية داخلية وحوكمة تمنع تقديم المخرجات بوصفها حكمًا أو رأيًا نهائيًا.

## 3. المشكلة التي يعالجها المشروع

1. تشتت النصوص النظامية والوقائع والمرفقات والملاحظات بين أدوات مختلفة.
2. صعوبة تحويل السؤال العام إلى مسألة قانونية محددة ومصادر قابلة للتحقق.
3. خطر اختلاق أرقام المواد أو الاستناد إلى نص غير موجود عند استخدام نموذج لغوي عام.
4. غياب الذاكرة المنظمة للجلسة والقضية في المحادثات العامة.
5. استهلاك الوقت في تلخيص ملفات القضايا وبناء الخط الزمني ومصفوفة الإثبات ومراجعة المدد.
6. الحاجة إلى محاكاة تعليمية للإجراءات والمرافعة دون إيهام المستخدم بأنها جهة قضائية.

## 6. رحلة المستخدم

1. يزور الصفحة العامة ويختار التسجيل أو الدخول.
2. تتم المصادقة عبر Clerk أو جلسة حكيم الأصلية بحسب الإعداد.
3. يصل إلى لوحة تجعل السؤال نقطة البداية.
4. يطرح سؤالًا، يرفق نصًا، أو يفتح قضية.
5. يحدد النظام الحصة/الرصيد ويبدأ مهمة قابلة للاستئناف.
6. يسترجع من النواة أو يطلب استيضاحًا عند نقص الوقائع.
7. يعرض الإجابة مع أساسها وتحذيراتها.
8. يحفظ الجلسة ويستعيدها لاحقًا.
9. ينتقل عند الحاجة إلى المعاون أو المحاكاة أو الوثائق أو النواة.
10. يدير ملفاته واستخدامه واشتراكه من مساحته.

## 14. أقوى عناصر التميز المثبتة

1. ربط السؤال القانوني بمصدر حقيقة داخلي وحراس استشهاد.
2. محرك جلسات موحد ونتائج قابلة للاستئناف.
3. معاون قضائي يضم 24 عملًا مرتبطًا بمرحلة القضية.
4. منصة وثائق تعمل محليًا في المتصفح وتقدم فحصًا وبحثًا وتصديرًا.
5. نموذج معرفة قانونية يجمع الزمن والعلاقات والمتجهات والأحكام والفقه تحت مراجعة.

## 15. القيود والفجوات ذات الأولوية

1. فرض إعداد إنتاج يمنع تمامًا guest SYSTEM_ADMIN.
2. تشغيل اختبار أمني آلي على جميع المسارات الديناميكية وملكية الموارد.
3. توحيد الخدمات المتوازية: legal-rag، legal-chat، case-analysis، legal-agent، وAsk.
4. إكمال pipeline استخراج النص لمسار المرفقات العام.
5. إثبات تحديث النواة ومصادرها وإحصاءاتها من قاعدة الإنتاج.
6. اختبار الدفع والاشتراك والفواتير والويب هوك نهاية إلى نهاية.
7. توثيق الاحتفاظ والحذف والتشفير والتعامل مع مزودي الذكاء وفق PDPL.
8. ربط CI موحد بالالتزام وإظهار نتائج البناء والاختبارات والأمن.

## 16. ما يجوز قوله بثقة

- حكيم منصة قانونية سعودية متعددة الأدوات تربط السؤال والقضية والمستند بالنواة القانونية.
- يضم نظام جلسات، نواة قانونية، معاونًا قضائيًا، محاكاة تدريبية، ومنصة وثائق.
- يحتوي ضوابط للاستشهاد والتدقيق والصلاحيات والاستخدام.
- يوفر 24 خدمة داخل المعاون القضائي وفق كتالوج ومشغلات برمجية.

## 17. ما لا يجوز ادعاؤه حاليًا

- أنه جهة قضائية أو قاضٍ رسمي.
- أنه بديل عن المحامي أو قرار القاضي.
- أنه معتمد حكوميًا.
- أنه دقيق 100% أو يمنع التلفيق مطلقًا.
- أنه متوافق بالكامل مع PDPL أو أي معيار أمني دون تدقيق مستقل.
- أن جميع الأنظمة والأحكام محدثة ومكتملة دون إحصاء إنتاج موثق.
- أن بوابة الدفع والتكاملات الخارجية مفعلة حاليًا دون فحص البيئة.

## 18. منهج الفحص وحدوده

- فحص ساكن عبر GitHub على الالتزام المحدد.
- اكتُشف **68 ملف صفحة** على الأقل من نتائج البحث البرمجي.
- اكتُشف **145 ملف مسار Route متميزًا على الأقل** عبر اتحاد نتائج GET وPOST وPATCH؛ الرقم حد أدنى لأن البحث قد لا يلتقط المسارات التي لا تحتوي هذه الصيغ.
- فُحصت ملفات محورية في المصادقة، Ask، الجلسات، النواة، المعاون، المحاكاة، المرفقات، الوثائق، التسعير، والمخطط.
- تعذر استنساخ المشروع محليًا بسبب حجب DNS في بيئة التنفيذ؛ لذلك لم تُشغّل اختبارات أو build محليًا.
