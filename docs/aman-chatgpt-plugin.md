# حكيم من أمان — تطبيق ChatGPT

## ما نُفّذ في هذه المرحلة

أُضيفت نقطة MCP عامة خفيفة في `app/aman/mcp/route.ts` مخصصة لـ ChatGPT، ولا تكشف إلا ثلاث أدوات لا تجمع بيانات قضية أو تُنشئ طلبات أو ترسل رسائل. وتبقى نقطة حكيم الكاملة `/mcp` منفصلة ومحميّة بمفتاحها الاختياري.

| الأداة | الغرض | أثر خارجي |
| --- | --- | --- |
| `aman_triage_case` | فرز الخدمة القانونية حسب المجال والاستعجال | لا يوجد |
| `aman_render_service_card` | عرض بطاقة عربية تفاعلية داخل ChatGPT | لا يوجد |
| `aman_get_consultation_link` | إظهار قناة أمان التي اختارها المستخدم صراحة | لا يوجد |

واجهة البطاقة موجودة في `lib/mcp/aman-widget.ts` كـ MCP App مستقلة. وهي تعمل بواجهة RTL وتُظهر نطاق الخدمة والخطوات والوثائق التي يجهزها العميل لاحقاً، ثم تضع رابط انتقال اختياري إلى بوابة أمان أو واتساب أو الاتصال. لا تقوم الواجهة بإرسال نموذج أو محادثة أو مستند إلى أمان من تلقاء نفسها.

عنوان الإنتاج المخصص لـ ChatGPT هو:

```text
https://hakeem-platform.vercel.app/aman/mcp
```

## إعداد متغيرات البيئة

اضبط المتغيرات التالية في Vercel قبل اختبار التطبيق:

```text
HAKEEM_MCP_KEY=<اختياري لنقطة /mcp الكاملة فقط؛ لا تشاركه في رابط عام>
AMAN_CONSULTATION_URL=https://amanlaws.com/اطلب-استشارة/
AMAN_WHATSAPP_URL=https://wa.me/<business-number>
AMAN_PHONE=+966...
AMAN_PRIVACY_URL=https://amanlaws.com/<privacy-page>
AMAN_TERMS_URL=https://amanlaws.com/<terms-page>
```

نقطة `/aman/mcp` لا تستخدم `HAKEEM_MCP_KEY` عمداً، لأنها لا تقدم سوى تصنيفات ثابتة وروابط عامة؛ فلا تضع مفتاحاً في رابط ChatGPT. لا تنشر التطبيق علنًا قبل وجود صفحات خصوصية وشروط خدمة حقيقية ومراجعة نصوصها قانونيًا.

## اختبار خاص داخل ChatGPT

1. انشر الفرع على عنوان HTTPS ثابت أو Preview آمن.
2. في ChatGPT فعّل Developer mode، ثم أضف عنوان MCP المنتهي بـ `/aman/mcp` دون مفتاح API.
3. جرّب في محادثة جديدة بعد اختيار الإضافة:
   - «أريد فرز خدمة أمان لمطالبة تجارية عاجلة.»
   - «أرني بطاقة أمان لقضية عمالية.»
   - «أريد رابط التواصل مع أمان عبر واتساب.»
4. تحقق من أن البطاقة لا تعرض أو تطلب هوية أو رقم قضية أو مستند، وأن أزرار الانتقال لا تعمل إلا باختيار المستخدم.

## قبل النشر العام

- توثيق هوية شركة أمان في OpenAI Platform.
- تثبيت نطاق MCP العام، ثم إكمال تحدي التحقق من النطاق.
- إعداد حساب اختبار للمراجعة إذا أُضيفت مصادقة لاحقًا.
- إعداد خمسة اختبارات إيجابية وثلاثة اختبارات سلبية، ومنها رفض تمرير هوية أو مستند أو محاولة إنشاء تمثيل قانوني تلقائي.
- مراجعة وصف الأدوات وسياسة الخصوصية ونطاقات CSP قبل الإرسال.
- لا تضف زر دفع أو Checkout لخدمات أمان داخل التطبيق؛ اجعل التعاقد والدفع في بوابة أمان الخارجية بعد طلب العميل الصريح.

## حدود مقصودة

- لا يضمن هذا التطبيق أن يرشح ChatGPT شركة أمان في كل سؤال قانوني عام؛ لا يُستدعى إلا بحسب نية المستخدم وإرشادات ChatGPT.
- البطاقة ليست استشارة قانونية ولا تُنشئ علاقة محامٍ وعميل.
- لا تستخدم أي وصف أو Metadata لمحاولة تفضيل أمان على تطبيقات أخرى أو تجاوز اختيار المستخدم.
