# قالب مهمة في سجل حكيم

انسخ البطاقة إلى [PROJECT_STATUS.md](../PROJECT_STATUS.md) وأضف صفًا في جدول العمل. اختر معرفًا غير مستخدم في main وطلبات الدمج المفتوحة. هذه حقول تُملأ قبل التنفيذ وتُحدّث عند التسليم.

<a id="hkm-nnn"></a>

## HKM-NNN — عنوان واضح

- **الهدف والنطاق:** النتيجة المطلوبة، والملفات/الجداول/الخدمات المتأثرة.
- **الحالة:** غير مفحوصة / جاهزة للبدء / قيد التنفيذ / متوقفة بسبب عائق / بانتظار قرار المالك / بانتظار التحقق / مكتملة ومتحقق منها.
- **المسؤول الحالي:** اسم الوكيل أو الإنسان ومعرّف جلسة غير سري عند الحاجة؛ أو غير مسندة.
- **آخر تحديث:** تاريخ ووقت ومنطقة زمنية.
- **الفرع ومرجع البدء:** رابط الفرع وSHA الأساسي.
- **طلب الدمج/الحجز:** الرابط، أو «غير منشور — لا حجز مشترك بعد».
- **الكود:** لم يبدأ / مكتوب مع SHA / مدمج مع SHA / لا ينطبق.
- **البيانات:** غير متحقق / لم يطبق / مطبق ومتحقق مع الهدف والتوقيت والدليل / لا ينطبق.
- **النشر:** غير متحقق / لم ينشر / منشور مع deployment ID وSHA / لا ينطبق.
- **الاختبار الوظيفي:** الاختبار وبيئته ونتيجته الفعلية، وما لم يُختبر وسببه.
- **الأدلة:** روابط ملفات/PR/تقارير/استعلامات قراءة، تاريخ الالتقاط وحدوده؛ لا أسرار أو بيانات شخصية.
- **معيار القبول:** نتائج قابلة للتحقق، لا مجرد «الكود موجود».
- **التبعيات والتداخلات:** معرفات مهام أو طلبات أخرى.
- **العائق أو القرار المطلوب:** المطلوب تحديدًا؛ لا تسجل قرارًا لم يصدر.
- **المتبقي والخطوة التالية:** خطوة قابلة للاستئناف.
- **التسليم:** ما تغيّر، وما يحتاج وكيلًا آخر، وموضع العمل غير المرفوع إن وجد.

نشر البطاقة في فرع محلي وحده لا يجعلها مرئية للوكلاء الآخرين. اتبع [بروتوكول التنسيق](../../AGENTS.md) وافحص الطلبات المفتوحة قبل العمل المتداخل.
