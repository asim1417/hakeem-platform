# 13 — جرد الخدمات والأيقونات غير الفعّالة («قريبًا»)

هدف التسويق قبل الإطلاق: أي خدمة أو أيقونة تظهر للمستخدم وهي غير جاهزة تُوسم صراحةً بـ **قريبًا** بدل الصمت أو الادّعاء الكاذب.

## المكوّنات المشتركة

| المكوّن | المسار | الاستخدام |
|---|---|---|
| `ComingSoonBadge` | `components/ui/ComingSoon.tsx` | شارة نصية موحّدة |
| `ComingSoonControl` | نفس الملف | زر معطّل + شارة |
| `ComingSoonBanner` | `components/ui/ComingSoonBanner.tsx` | شريط أعلى صفحة خدمة غير جاهزة |
| `ModuleCard.comingSoon` | `components/ModuleCard.tsx` | بطاقة بلا رابط + شارة |

## ما وُسم بـ «قريبًا»

| السطح | المعاملة |
|---|---|
| المختبر: رسم معرفي / RAG / تدريب | بطاقات `comingSoon` + بانر على الصفحات المباشرة |
| رابط المختبر من الوكلاء | شارة قريبًا |
| فلاتر النواة القانونية الوهمية | شارات على كل شريحة |
| أنواع مصدر البحث (شرح/حكم/مقارن) | `disabled` + قريبًا |
| ملفات داعمة / مفضلة بلا معرّف | `ComingSoonControl` |
| تبويبات مادة ناقصة + شرح/مقارن | شارات |
| تحميل حكم بالنقاط | `ComingSoonControl` (لا تحميل فعلي بعد) |
| صرف النقاط في CreditsWidget | قائمة مع (قريبًا) |
| Drive على هبوط المستندات + CaseBrowser غير مهيّأ | قريبًا |
| مرفقات: تخزين سحابي / استخراج نص | بانر + تذييل |
| خطط مدفوعة عند إيقاف checkout | نص/شارة قريبًا (فوترة، عدّاد حصّة، تسعير فريق) |
| فهرس عكسي / اعتماد استشهادات الجلسة | قريبًا للحفظ الدائم |
| رابط الواجهة الكلاسيكية للقاضي | مخفى (`null`) |

## ما اعتُبر فعّالًا (لا قريبًا)

- اسأل حكيم، الاستشارات، القاضي التفاعلي، المساعد القضائي (JS-001…024)
- النواة القانونية: أنظمة/مواد/أحكام/بحث أساسي
- المستندات المحلية (رفع، OCR محلي، بحث، جداول، تصدير) عند توفرها في التطبيق
- Google Drive داخل CaseBrowser **فقط** عند `driveConfigured === true`

## ملاحظات تشغيل

- بطاقات المختبر لا تنتقل للصفحات؛ الدخول المباشر بالرابط يعرض بانرًا تسويقيًا مع معاينة محدودة.
- لا تُعرض نصوص `TODO` أو رموز تقنية للمستخدم النهائي.
