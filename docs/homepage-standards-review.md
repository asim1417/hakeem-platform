# مراجعة الصفحة الرئيسية — المعايير الوطنية والعالمية

## الحكم التنفيذي

لا يوجد «كود عالمي» واحد يحكم جميع الصفحات الرئيسية. المرجعية العملية المستخدمة في حكيم هي:

1. كود المنصات السعودي ومبادئ هيئة الحكومة الرقمية: الاتساق، سهولة الوصول، وتمحور التجربة حول المستخدم.
2. WCAG 2.2: الوصول، أحجام الأهداف، التركيز المرئي، والمصادقة القابلة للاستخدام.
3. مبادئ تصميم المحتوى: الاختصار، قابلية المسح البصري، وإظهار القيمة قبل التفاصيل.

وجود فيديو ليس شرط امتثال، لكنه وسيلة فعالة لشرح المنتج عندما يكون قصيرًا، اختياري التشغيل، ومصحوبًا بترجمة نصية.

## ما نُفذ

- تقليل النصوص المتكررة والعبارات الإنشائية.
- جعل الواجهة تبدأ بالقيمة والإجراء الرئيس.
- إضافة جولة مرئية تشرح مراحل العمل داخل حكيم.
- منع التشغيل التلقائي للفيديو.
- عدم تحميل الفيديو إلا عند توفر رابطه وترجمته النصية العربية.
- الإبقاء على شرح نصي مكافئ للمستخدم الذي لا يشغّل الفيديو.
- إبراز الخدمات الست والمؤشرات الحية والقدرات التشغيلية.

## تفعيل المقطع الترويجي

تُضاف القيم التالية إلى Vercel في بيئات Preview وProduction ثم يعاد النشر:

```env
NEXT_PUBLIC_HOME_VIDEO_URL="https://cdn.example.com/hakeem-tour.mp4"
NEXT_PUBLIC_HOME_VIDEO_POSTER_URL="https://cdn.example.com/hakeem-tour-poster.webp"
NEXT_PUBLIC_HOME_VIDEO_CAPTIONS_URL="https://cdn.example.com/hakeem-tour-ar.vtt"
```

لن يعرض المكوّن الفيديو الفعلي إذا غاب ملف الترجمة النصية، وسيبقى مكانه عرض تعريفي بديل.

## مواصفات المقطع

- مدة مستهدفة: 45–75 ثانية.
- نسبة العرض: 16:9.
- عدم التشغيل التلقائي.
- ترجمة عربية بصيغة WebVTT.
- صورة غلاف واضحة وخفيفة.
- عرض رحلة واحدة: إدخال الوقائع، ظهور السند، ثم حفظ ملف القضية.
- تجنب الموسيقى المرتفعة والنصوص الصغيرة داخل الفيديو.
