# خصوصية جسر رصد حكيم المحلي

قبل الاقتران، اعلم أن الوكيل يرسل إلى منصة حكيم فقط:

- معرف الوكيل وإصداره ونظام التشغيل
- نتائج فحص صحة المصادر الرسمية
- لقطات/نصوص من نطاقات `.gov.sa` المسموحة ضمن مهام الرصد
- مؤشرات التشغيل (heartbeat، أخطاء منضبطة)
- رمز دولة الخروج عند توفره (وليس بالضرورة عنوان IP كامل)

لا يجمع الوكيل:

- ملفاتك الشخصية
- سجل التصفح
- عناوين الشبكة المحلية
- بيانات غير لازمة للرصد التشريعي

المفتاح الخاص يبقى على جهازك ولا يُرفع إلى حكيم.
