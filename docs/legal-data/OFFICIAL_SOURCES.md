# سياسة مصادر الأنظمة السعودية في حكيم

## الهدف

إنشاء كوربوس تشريعي سعودي قابل للتحقق والتحديث دون إنشاء «مصدر حقيقة» موازٍ لـ `legal_articles`، ودون كشط يتجاوز ما تسمح به الجهات الرسمية.

## ترتيب المصادر

| المصدر | دوره في حكيم | الجمع الآلي |
|---|---|---|
| المركز الوطني للوثائق والمحفوظات (NCAR) | المصدر الأساسي لجرد الوثائق والأنظمة واللوائح وحالة النفاذ | نعم، عبر البيانات المفتوحة المقروءة آلياً متى نُشر رابطها؛ وإلا من الصفحات الرسمية بمهلة وحدود طلبات |
| هيئة الخبراء بمجلس الوزراء (BOE) | مطابقة النص المجمّع، بيانات الإصدار/النشر، التحديثات وحالة النظام | نعم، من الواجهات العامة الرسمية فقط وبلا افتراض API غير معلن |
| جريدة أم القرى (UQN) | إثبات النشر ورصد الجديد | لا كشط شامل؛ RSS/واجهة منشورة للاستهلاك الآلي فقط أو موافقة صريحة |

## قواعد حاكمة

1. لا CAPTCHA bypass ولا WAF bypass ولا تدوير عناوين أو محاولات التفاف.
2. HTTPS فقط، والنطاقات الرسمية في allowlist.
3. لا إرسال Cookie أو Authorization أو مفاتيح وصول إلى المصادر.
4. كل نسخة خام تحفظ مع `SHA-256` ووقت الجلب والرابط ونوع المحتوى.
5. لا تُستبدل مادة نافذة تلقائياً بسبب اختلاف مصدر؛ الاختلاف يذهب إلى مسار مراجعة.
6. لا يُفترض وجود API لـ NCAR أو BOE. متغير `NCAR_OPEN_DATA_URL` يُملأ فقط برابط رسمي منشور فعلاً.
7. يظل `legal_articles` واجهة التوافق الحالية، بينما `LegalDocument/DocumentUnit` تحفظ الوثيقة الكاملة ومصدرها وسياقها.
8. بعد أي إدخال: تدقيق الأرقام → مطابقة عدد المواد → اشتقاق النسخ → تحديث الفهارس BM25/embedding → اختبارات RAG والاستشهاد.

## التشغيل

معاينة بلا أي طلبات شبكة:

```bash
npm run fetch:official
npm run fetch:official -- --source=ncar --limit=100
```

الجلب الفعلي في بيئة مسموح لها بالوصول للمصدر:

```bash
npm run fetch:official -- --apply --source=ncar --limit=100
npm run fetch:official -- --apply --source=boe --limit=100
```

وإذا نُشر رابط بيانات مفتوحة رسمي مباشر من NCAR:

```bash
NCAR_OPEN_DATA_URL="https://ncar.gov.sa/..." npm run fetch:official -- --apply --source=ncar
```

## معايير الاعتماد

لا يوصف المصدر بأنه «متصل» أو «تم جلبه بالكامل» إلا إذا:
- نجح اختبار حي من بيئة التشغيل الفعلية.
- عُرف عدد السجلات التي اكتُشفت وجُلبت وفشلت.
- حفظت البصمات والروابط.
- اجتازت العينة تحققاً يدوياً، ثم اجتاز الكوربوس بوابات سلامة أرقام المواد والتكرار والانزياح.
