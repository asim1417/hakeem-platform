# جاهزية إطلاق قاعدة الأنظمة — المعيار الحاكم

هذه الوثيقة تجعل «READY» صفة مُثبتة وليست وصفًا يدويًا. لا يظهر النظام في طبقة الوثائق النظامية المتحققة إلا بعد اجتياز جميع البنود الحاكمة.

## 1) سلامة المواد ومنع الزحف

لكل نظام:
- تسلسل المواد الموجبة يبدأ من (1) ويخلو من الفجوات.
- رقم المادة يطابق الرقم الترتيبي الوارد في عنوانها عندما يكون العنوان قابلًا للتحليل.
- لا يوجد نص مكرر بين مادتين إلا إذا كان التكرار مثبتًا رسميًا ويُعالج كحالة خاصة.
- عدد `legal_articles` يساوي `legal_systems.articleCount`.
- عدد وحدات `ARTICLE` في نص النظام الرسمي يطابق عدد المواد في القاعدة.
- أنظمة ذات واقعة خطأ تاريخية معروفة تملك مراسي إضافية. حاليًا:
  - نظام المعاملات المدنية: 721 مادة.
  - المادة 236 تبدأ بحكم تعدد المدينين.
  - المادة 237 تبدأ بحكم تعدد الدائنين.
  - المادة 238 هي بداية حوالة الحق.
  - المواد 466 و469 و475 و721 لها مراسٍ مستقلة لمنع تكرار انزياح +1.

أي إخفاق = `NOT_READY`.

## 2) الحزمة الرسمية للنظام

الحزمة لا تقتصر على «مواد النظام». بحسب نوع النظام/الأداة تشمل:
1. المرسوم الملكي أو أداة الإصدار.
2. قرار مجلس الوزراء المشار إليه في المرسوم، إذا ورد.
3. النص الكامل للنظام.
4. اللوائح/الأدوات ذات الصلة عند إدخالها لاحقًا.
5. التعديلات ونسخ المواد الزمنية في جداول التعديلات/الإصدارات.

### المرسوم الملكي

يجب حفظه كاملًا من الافتتاحية إلى الخاتمة، وتقسيمه إلى:
- `INSTRUMENT_OPENING`
- `RECITAL` لكل «بناءً على/بعد الاطلاع»
- `INSTRUMENT_CLAUSE` لكل بند من منطوق «رسمنا بما هو آت»
- `INSTRUMENT_CLOSING`
- `SIGNATURE` عند إمكان التقاطها

وجود رقم المرسوم في `legal_articles.royalDecree` **لا يغني** عن حفظ نص المرسوم؛ لأن بنود المرسوم قد تتضمن إلغاءً أو أحكامًا انتقالية أو نطاق تطبيق أو نفاذًا مستقلًا عن مواد النظام.

## 3) قرار مجلس الوزراء

يُستخرج رقم وتاريخ أي «قرار مجلس الوزراء رقم (...) وتاريخ ...» من نص المرسوم.

إذا وُجد المرجع:
- يجب أن توجد وثيقة مستقلة من نوع `COUNCIL_DECISION`.
- يجب أن يطابق رقمها الرقم الوارد في المرسوم.
- إذا توفر التاريخ في الوثيقتين فيجب أن يتطابق.
- يجب حفظ منطوق القرار كوحدات `INSTRUMENT_CLAUSE`.
- القرار لا يُختزل إلى رقمه؛ تحفظ ديباجته ومداولاته ومنطوقه.

مثال معياري: نظام المعاملات المدنية — المرسوم الملكي م/191 يشير إلى قرار مجلس الوزراء رقم 820.

## 4) الأمانة النصية

لكل `LegalDocument`:
- `rawText` هو النص الخام الحاكم.
- مجموع `DocumentUnit.textRaw` حسب `ordinal` يجب أن يعيد `rawText` حرفيًا.
- `contentSha256` يحسب من `rawText`.
- أي اختلاف في البصمة أو إعادة التركيب = مانع إطلاق.

## 5) المصدر والتحقق

الوثيقة الجاهزة يجب أن تحتوي على:
- `sourceUrl` رسمي.
- `sourceCode`: NCAR أو BOE أو UQN.
- `contentSha256`.
- `verificationStatus` ليس UNVERIFIED ولا REVIEW_REQUIRED.

الحالات:
- `SOURCE_MATCHED`: النص جُلب من مصدر رسمي واحد والتحقق البنيوي نجح.
- `CROSS_SOURCE_MATCHED`: تمت مطابقته مع مصدر رسمي آخر.
- `REVIEW_REQUIRED`: يوجد تعارض أو التباس.
- `UNVERIFIED`: لا يعتمد للإطلاق.

## 6) حالة إطلاق النظام

`LegalSystem.launchStatus`:
- `NOT_READY`: يوجد مانع حاكم.
- `REVIEW_REQUIRED`: لا يوجد مانع صريح، لكن توجد ملاحظة تتطلب مراجعة بشرية.
- `READY`: لا مانع ولا ملاحظة مفتوحة.

`launchIssues` يحفظ أسباب القرار، و`launchValidatedAt` يحفظ وقت آخر تدقيق.

## 7) الاسترجاع في حكيم

المواد النظامية تبقى في `legal_articles`.
أما أحكام المرسوم وقرار مجلس الوزراء والتمهيدات فتُسترجع من `document_units` عبر:
- `searchInstrumentProvisions`
- `getSystemInstrumentBundle`

البحث الافتراضي في هذه الطبقة مقصور على:
- أنظمة `READY`.
- وثائق `SOURCE_MATCHED` أو `CROSS_SOURCE_MATCHED`.

وبذلك لا تصبح أحكام المرسوم «مخزنة فقط» بل قابلة للاستدعاء والإسناد.

## 8) أوامر التشغيل

بعد تطبيق الهجرات:

```bash
npm run backfill:doc-provenance
npm run audit:legal-launch -- --law="نظام المعاملات المدنية"
```

لإدخال حزمة وثائق:

```bash
npm run backfill:legal-bundle
CONFIRM_RUNTIME_DB_ALIGNMENT=NEON_RUNTIME_CONFIRMED npm run backfill:legal-bundle -- --apply
```

لتحديث حالات الجاهزية بعد اكتمال البيانات:

```bash
CONFIRM_RUNTIME_DB_ALIGNMENT=NEON_RUNTIME_CONFIRMED npm run audit:legal-launch -- --apply --strict
```

## 9) شرط الإطلاق

قاعدة الأنظمة لا توصف بأنها جاهزة للإطلاق إلا عندما:
- جميع الأنظمة المراد إطلاقها = READY.
- نظام المعاملات المدنية يجتاز حارس الزحف الخاص به.
- لا توجد وثيقة حاكمة مفقودة.
- لا توجد إحالة إلى قرار مجلس الوزراء دون وثيقته.
- لا توجد وثيقة بلا مصدر رسمي وبصمة.
- تمر اختبارات CI الخاصة بالمصادر والقارئ والترقيم والجاهزية.
