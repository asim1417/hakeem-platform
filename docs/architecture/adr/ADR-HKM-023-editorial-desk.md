# ADR HKM-023: مكتب تحرير قابل لإدارة السياسات

التاريخ: 2026-10-17. الحالة: مقترح ضمن PR #723؛ غير مدمج. يتداخل مع #727 ويجب توحيد التنفيذ قبل الدمج.

## القرار

إضافة مكتب عربي RTL تحت `/admin/legal` باستخدام Refine Core 5.0.12 في مشروع Next القائم. يعاد استخدام hooks ومزود البيانات؛ تبقى قواعد الاعتماد والتدقيق والمعاملات في خادم حكيم. لا تمنح واجهة Refine صلاحية مباشرة على الجداول.

الأدوار، أذونات الدور، تكليف المستخدم، نطاق نوع العنصر والمجال، الحد الأدنى للموافقات، استثناء المالك، قوالب المهام وتسميات الوثائق وأدوات الإصدار محفوظة في نسخ إعدادات إضافية وتعدّل من نماذج اللوحة. التغيير ينفذ في معاملة تقرأ الصلاحيات الحالية. الوكيل يقترح فقط، وSYSTEM_ADMIN لا يرث وصول التحرير تلقائيًا.

العمليات التجارية محصورة بمعالجات معروفة ومتحقق منها على الخادم. إنشاء دور أو إعادة إسناد مهمة لا يحتاج تعديل كود؛ اختراع إجراء تجاري جديد يحتاج معالجًا واختبارًا. لا تسمح اللوحة بإدخال SQL أو JavaScript للتنفيذ.

## نمط البيانات

جداول جديدة: change_set، editorial_change، review_decision، audit_event، editorial_config، editorial_work_version، editorial_source_snapshot، editorial_task، index_sync. لا تعديل أعمدة الجداول القائمة. النشر يضيف verification/unit_version أو نسخ بيانات وصفية، والتحكيم يضيف amendment_review أو يعدّل حالة مراجعة المبدأ/الحكم. لا يستبدل `legal_articles.content` أو حالته القديمة.

تثبت حمولة التغيير منذ إنشائها، وتراجع بصمة النسخة قبل النشر. فشل عنصر يلغي المعاملة كلها. التدقيق والقرارات والنسخ لا تقبل UPDATE/DELETE عبر مشغلات PostgreSQL. فهارس جزئية تمنع الطلبات المفتوحة المتكررة. التراجع المتاح ينشئ تغييرًا تعويضيًا ولا يحذف السند الأصلي.

كل كتابة جديدة تتطلب EDITORIAL_DESK_WRITE=1. لا Runtime DDL. الترحيل جرّب فقط في Neon `br-red-resonance-aq7h1zdf`؛ الإنتاج لم يتغير. مراقبة outbox وإعادة المحاولة الدورية تحتاج تشغيلًا منفصلًا قبل التعهد بمهلة خمس دقائق.

## التبعات

إدارة العمليات المعرّفة أصبحت قابلة للتهيئة، مع سجل لسبب تغيير الصلاحيات. التغيير لا يمثل شهادة امتثال نظامي سعودي: مسمى الوثيقة وأداة الإصدار حقول منفصلة، ودليل الاختصاص والمصدر يحتاج مراجعة بشرية. تقارير القبول وحدود التنفيذ في `reports/editorial-desk-phase-0-1.md`.
