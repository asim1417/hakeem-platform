## بروتوكول كل دفعة (اتبعه حرفيًا)

1. **القراءة والمراجعة:** يقرأ قارئ أول ويكتب `readings/*.jsonl`، ثم يراجعه مراجع مستقل ويكتب `verify.jsonl`. أعطِ الوكلاء الفرعيين ملف القواعد المشترك. نسخة منه كانت في scratchpad الجلسة السابقة ولم تُرفع، فأعد كتابتها من هذا القسم.
2. **ملف البناء:** `data/review/hkm047-<الاسم>-<التاريخ>/build.py` يكتب `statements.json` (`md5`، `count`، `report`، `statements`). وإن أضاف الملف مواد أو أنظمة فأضف `expect_delta`.
   - **حارس قبل وبعد:** `SELECT CASE WHEN … THEN 'ok' ELSE (1/(SELECT count(*) FROM legal_systems WHERE false))::text END`. لا تستعمل `1/0` الثابت، فـ PostgreSQL يطويه عند التخطيط فيفشل الحارس دائمًا.
   - **الاستبدال داخل القاعدة:** `replace(<النص الأساس>, old, new)`، وفي شرط WHERE أن `old` يرد مرة واحدة: `(length(x)-length(replace(x,old,'')))/length(old)=1`.
   - **النص الساري:** أحدث `unit_version` بـ `valid_from <= now()` (`ORDER BY valid_from DESC, created_at DESC`)، وإلا `legal_articles.content`.
   - **نسخة تعديل:** `valid_from = greatest(تاريخ النفاذ, max(valid_from القائم)+1s)`، وتُبنى على نص آخر نسخة. وإن رُكّبت بعد نسخة لاحقة فاذكر ذلك في `evidence_quote`. اتبع النمط في `data/review/hkm045g-item12-text-2026-10-24/build.py`.
3. **فحص محلي:** `python3 scripts/apply-statements.py --file … --mode preview --expect-md5 <md5>` يجب أن يقف عند «DATABASE_URL غير مضبوط»، فهذا يعني أن العبارات اجتازت البوابة.
4. التزام برسالة عربية فيها `Changelog` يذكر الأعداد، ثم طلب دمج، ثم الدمج بعد اعتماد المالك.
5. **نقطة استرجاع:** `mcp__Neon__create_branch`، والأب `br-rapid-salad-aq782ea2`، و`no_compute: true`. سجّل معرّفها.
6. **التطبيق:** workflow `apply-statements.yml` بمدخلاته `CONFIRM_RUNTIME_DB_ALIGNMENT=NEON_RUNTIME_CONFIRMED` و`file` و`expect_md5` و`allow_guarded_update` (no/yes) و`mode`. شغّل `preview` أولًا، ثم `apply` بالبصمة نفسها. إن فشل فاقرأ سجل المهمة: يذكر رقم العبارة والشروط الفاشلة.
7. **بعد التطبيق:**
   - حدّث `search_norm` للمواد المتغيرة:
     `UPDATE legal_articles a SET search_norm = uqn_fix.hkm30_search_norm(a."lawName", a.title, <النص الساري>, a.keywords, a.classification, a.chapter)`
     وهذا مسموح عبر Neon MCP لأنه بيانات وصفية.
   - ثم المتجهات: نفّذ استعلام `node scripts/hkm-029/embed-lib.mjs --print-summary-sql` قراءة، ثم جمّد بـ `freeze-manifest.mjs --chars N` وادمج، ثم شغّل `backfill-embeddings.yml` بـ `target=articles` و`scope=all` و`limit=N`.
8. **التوثيق:** صف في `docs/PROJECT_STATUS.md` بالبصمة وأرقام التشغيل ونقطة الاسترجاع والعدّ وما بقي. وقياس صحة بـ `scripts/db-health.sql` يُحفظ في `data/health/`. آخر قياس: `2026-10-24-after-hkm045.json`.
