# خصوصيّة مسجّل حكيم الصوتي (HKM-VOICE-NOTE-SA-007 §15)

## المبدأ: Local-First — Upload Only After Consent
- التسجيل يبقى **Blob محليًّا** في المتصفّح.
- **لا رفع** أثناء التسجيل، ولا عند الإيقاف تلقائيًّا.
- الرفع **فقط** بعد ضغط «تحويل إلى نص» (موافقةٌ صريحة).
- يُحذف الـBlob بعد نجاح التفريغ أو فشله (`URL.revokeObjectURL` + إسقاط المرجع).

## ما لا يُخزَّن ولا يُرسَل
- لا صوت في قاعدة البيانات.
- لا صوت في Blob Storage افتراضيًّا.
- لا صوت في Analytics ولا Error Tracking.
- لا `AuditEvent` يحمل نصًّا أو بايتات صوت.
- لا تُرسَل إلى قائمة التلميحات: أسماء الأطراف، أرقام الهويّة/الجوّال، أو نصّ المرفقات (تُنقّى في `legal-phrase-list.ts`).

## Audit المسموح (بيانات وصفيّة فقط §15)
```
userId · organizationId · durationMs · byteSize · mimeType ·
provider · model · status · errorCode · createdAt
```

## المزوّدات
- المفاتيح **خادميّة فقط** — لا تظهر في العميل مطلقًا.
- في الطلب الإنتاجيّ يُختار **مزوّدٌ واحد** (+ احتياطيّ عند الفشل)، لا إرسالٌ لثلاثة.
- prompt المزوّد يقتصر على قاموس السياق القانونيّ — لا وقائع قضيةٍ كاملة.

## الحالة الآن
النواة النقيّة تُرسّخ هذه القيود (التنقية، فصل raw/normalized، بيانات Audit الوصفيّة). يُطبَّق مسار الرفع/الحذف الفعليّ في مرحلة الواجهة/الخادم — خلف أعلامٍ مطفأة.
