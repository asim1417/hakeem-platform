# قاعدة هيئة الخبراء المتكاملة (مخطط boe) — جاهزة للحقن

التاريخ: 2026-09-28. إضافة فقط. تنفيذ «أمر الوكيل — قاعدة هيئة الخبراء المتكاملة».

## ما في الحزمة

| المسار | المحتوى |
|---|---|
| data/boe_snapshots.jsonl.gz | لقطة كل صفحة نظام كما وردت من الهيئة (HTML) مع بصمة SHA-256 ووقت القراءة |
| data/boe_catalog.json | فهرس «الوثائق النظامية»: التبويب، والتصنيف، والاسم، والمعرّف |

| data/parsed/*.jsonl | الناتج المحلَّل: law، text_block، unit، amendment_note، related_doc |
| data/parsed/report.json | أعداد التحليل: الأصناف، وأنواع الأثر، والحالات، والشاذ |

| scripts/parse_snapshots.py | يحلّل اللقطات (حتمي، بلا شبكة) |
| scripts/load_boe.py | يحمّل boe.* إلى الهدف |
| scripts/match_and_diff.py | يربط بحكيم ويقارن المواد ويكتب boe.match وboe.diff وملف Excel للمالك |
| scripts/feed_law_cards.py | يغذّي law_card في حكيم للأنظمة المربوطة (عرض فقط) |
| dump/boe_full.sql.gz | القاعدة كاملة جاهزة: psql يحمّلها في أي قاعدة (المخطط + البيانات) |
| reports/مطابقة_هيئة_الخبراء_بحكيم.xlsx | ملف قرار المالك (يُولَّد على قاعدة حكيم الحقيقية) |

## الترتيب

```
# 0) لا شيء على الإنتاج قبل «احقن». الأهداف: staging (127.0.0.1) أو branch (فرع Neon) أو production.
python3 scripts/parse_snapshots.py                               # اختياري: يعيد التحليل من اللقطات
python3 scripts/load_boe.py --target branch --preview            # أرقام
python3 scripts/load_boe.py --target branch
python3 scripts/match_and_diff.py --target branch --xlsx reports/مطابقة_هيئة_الخبراء_بحكيم.xlsx
python3 scripts/feed_law_cards.py --target branch --preview      # يتطلب هجرة الموجة الأولى
# المالك يراجع ملف Excel. قراراته تُحقن لاحقًا صفوفًا جديدة (verification / amendment_review / unit_version).
# بعد «احقن»:
HAKEEM_INJECT=yes python3 scripts/load_boe.py --target production --preview
HAKEEM_INJECT=yes HAKEEM_APPROVED_ROWS=<العدد> python3 scripts/load_boe.py --target production
```

كل سكربت يفحص داخل المعاملة: حارسي md5، وعدد المخلوط 98/29/23، وعدد الأنظمة والمواد والتحقق،
وصفر حركة n_tup_upd/n_tup_del على legal_systems وlegal_articles وverification. أي خلل يلغي المعاملة.
الإنتاج: دفعة فوق 100 صف ترفض حتى يُمرَّر HAKEEM_APPROVED_ROWS بالعدد الذي وافق عليه المالك بعد المعاينة.

## قواعد القراءة (ما التُزم به)

- القراءة من متصفح المالك وبطلبه، صفحة كل 4 ثوانٍ على الأقل، وطلب واحد في الوقت نفسه، وتوقف 10 دقائق كل 200 صفحة.
- لا وسيط ولا التفاف على الحجب ولا تسجيل دخول ولا نماذج.
- الصفحة التي ردّت «العنصر المطلوب غير موجود بالنظام» تُسجَّل «غير موجودة في المصدر» ولا تُحلَّل.

## رصد المادة المعدلة أو الملغاة

- صنف المادة: changed-article / canceled-article / بلا صنف.
- نص الملاحظة يحدد الأثر: amend_article، amend_paragraph، amend_definition، repeal، delete، add، substitute_phrase، general، unclassified.
- الأداة (نوعها ورقمها وتاريخها) من الملاحظة نفسها. الملاحظة المكررة في الصفحة تُدوَّن مرة.
- needs_review = نعم إذا: الأثر عام أو غير مصنف، أو بلا أداة، أو بأكثر من أداة أو بند، أو تعديل بلا نص جديد صريح.
- النص المعروض في الهيئة هو الأصل. لا يُطبَّق تعديل على حكيم إلا بقرار المالك.
- الاتحاد مع أم القرى: ورقة «في أم القرى لا في الهيئة» وعمود «في أم القرى (op_id)» في ورقة تعديلات الهيئة.

## ما ثبت في الاختبار

- التحليل الجديد يطابق قراءة 28 سبتمبر السابقة حرفًا بحرف (بعد إهمال المسافات) في كل المواد المشتركة.
- نص كل مادة موجود حرفيًا في صفحتها (فُحص على 16,556 مادة من الفهرس: 16,554 مطابقة). الحالتان الباقيتان فيهما وسم HTML معيب في المصدر (SPAN)، وتُراجعان.
- التحميل الكامل على المختبر: 8 ثوانٍ، وإعادة التحميل تضيف صفرًا، وUPDATE على boe.* يُرفض.
- ملف dump/boe_full.sql.gz حُمّل في قاعدة فارغة بنجاح، ويرفض التحميل الثاني فوق بيانات قائمة.
- الربط يستبعد السجل المخلوط ويفك التعدد برقم المرسوم: «نظام التنفيذ» في الهيئة (م/237) رُبط بإصدار م/237 لا بالمخلوط، والسجل والأسماء بإصدار م/83.
- الكتل قبل المواد تعيد نص الصفحة سطرًا بسطر، وإلا وُسمت blocks_not_lossless.
- التطبيع في Python يطابق normalizeSystemName في TypeScript على كل الأسماء المختبرة (0 اختلاف).
- إعادة التحميل تضيف صفر صفوف، ومحاولة UPDATE/DELETE على boe.* ترفض.
